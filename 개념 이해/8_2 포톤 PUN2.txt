MonoBehaviourPunCallbacks :
Photon 네트워크에서 발생하는 이벤트를 쉽게 받을 수 있도록 만들어진 MonoBehaviour.
OnCreatedRoom나 OnJoinedRoom 함수를 자동으로 호출해준다.
내가 Photon에게 명령을 내리는 역할
예: 서버 연결, 방 생성, 플레이어 생성

PhotonNetwork : 
Photon 서버와 통신하고 네트워크 기능을 사용하는 정적 클래스다.
내 컴퓨터에서 실행된 동작을 다른 플레이어들에게서도 실행되게 함.
Photon이 결과를 알려주는 역할
예: 연결 완료, 방 입장 완료, 다른 플레이어 입장

-----------------------------------------------------------------------------------------

PhotonNetwork.NetworkClientState : 
지금 Photon 네트워크 클라이언트가 어떤 상태에 있는지"를 알려주는 값

PhotonNetwork.LocalPlayer : 
내 플레이어의 네트워크 정보 객체, 나 자신을 나타내는 Photon.Realtime.Player 객체

PhotonNetwork.ConnectUsingSettings() : 

호출 시 -> Name Server 연결 -> Master Server 연결 -> OnConnectedToMaster() 호출

ConnectUsingSettings()는 프로젝트의 PhotonServerSettings에 저장된 정보를 읽는다.
{
App ID
Region (Asia, Europe 등)
게임 버전(GameVersion)
프로토콜
}
등을 사용해서 적절한 Photon 서버에 연결한다.

OnConnectedToMaster() 왜 사용?
ConnectUsingSettings()는 비동기 함수.

PhotonNetwork.ConnectUsingSettings(); 호출 시, 

서버에 아직 연결 안 됐을 수도 있음
PhotonNetwork.JoinLobby(); -> 실패 가능성 존재

그래서 연결이 완전히 끝난 시점을 알려주는

public override void OnConnectedToMaster()
{
    PhotonNetwork.JoinLobby();
}

처럼 콜백 안에서 다음 작업을 수행하는 것이 올바른 사용법이다.

-----------------------------------------------------------------------------------------

Name Server : 
{
최초 연결
Region(Asia, Europe 등) 결정
어떤 Master Server로 갈지 알려줌
}
쉽게 말하면 "길 안내"

Master Server : 
{
로그인
플레이어 관리
로비 관리
방 생성
방 검색
방 입장
}
쉽게 말하면 "게임 접수 및 관리"

Game Server : 
(방에 들어갈 시 여기로 이동)
{
플레이어 위치 동기화
RPC
Instantiate
총알 발사
이동
}
같은 실제 게임 데이터를 주고받는다.

프로그램 실행
        │
        ▼
Master Server 연결
        │
        ▼
JoinLobby()      ← 로비 입장 (선택 사항)
        │
        ▼
CreateRoom()
또는
JoinRoom()
        │
        ▼
Room 입장
        │
        ▼

로비(Lobby)	
-방을 찾고 만드는 공간	
-방 목록을 받을 수 있음	
-게임은 아직 시작되지 않음	
-생략 가능	

방(Room)
-실제 플레이어들이 모이는 공간
-게임 플레이가 이루어짐
-플레이어 동기화, RPC 등 가능
-반드시 들어가야 게임 가능


꼭 로비에 들어가야 하나? 아니.

Photon에서는
PhotonNetwork.CreateRoom("Room1");
이나
PhotonNetwork.JoinRoom("Room1");
을 Master Server에 연결된 상태에서 바로 호출할 수 있다.

ConnectedToMaster
        │
        ├── JoinLobby() → 방 목록 보고 선택
        │
        └── CreateRoom() 또는 JoinRoom() → 바로 방 입장

처럼 로비를 생략할 수도 있다.
