###### **PhotonView :**

이 GameObject는 네트워크상에서 누구의 것인지, 그리고 어떤 데이터를 다른 플레이어에게 전달할 것인지 관리하는 컴포넌트



역할 : 내 GameObject -> PhotonView

\->Photon 네트워크 -> 다른 플레이어의 GameObject

형태로 데이터를 전달



네트워크상에서 객체를 식별 :

각 PhotonView에는 View ID를 보고 식별해.



객체의 소유자(Owner)를 관리 :

Owner 구별해서 이 객체를 누가 조작할 권한이 있는가?



데이터 동기화 :

A가 이동 -> A의 Transform 변경 -> PhotonTransformView

\-> Photon 네트워크 -> B의 화면 -> A의 캐릭터 이동

\------------------------------------------------------------------------------------------------------------------------

Observed Components :

이 PhotonView가 네트워크로 관찰하고 동기화할 컴포넌트는 무엇인가

###### **Photon Tranform View :**

내 컴퓨터에서 움직인 Transform의 위치와 회전을 다른 플레이어에게 자동으로 동기화해주는 컴포넌트



\------------------------------------------------------------------------------------------------------------------------

역할 : 한 컴퓨터에서 오브젝트 움직였다 해서 다른 컴퓨터에서 자동으로 적용 안 됨 ->

PUN2에서는:

PhotonView +

Photon Transform View

를 붙여서 Transform 정보를 네트워크로 동기화



PhotonView가 네트워크 객체를 관리하고,

PhotonTransformView가 이 객체의 Transform을 동기화하는 방법

을 담당한다

\------------------------------------------------------------------------------------------------------------------------

사용법 : 프리팹에 PhotonView와 Photon Transform View 붙이고

그리고 PhotonView의 Observed Components에 PhotonTransformView를 등록

\------------------------------------------------------------------------------------------------------------------------

동기화 대상 : Position, Rotation,Scale

\------------------------------------------------------------------------------------------------------------------------

Photon Transform View가 매 프레임 전부 네트워크로 보내는 게 아니야.

PUN의 직렬화 주기에 맞춰 Transform 상태를 네트워크 데이터로 만들어 전송



게임 실행

&#x20;  ↓

플레이어 계속 움직임

&#x20;  ↓

PhotonTransformView가 Transform 상태를 읽음

&#x20;  ↓

Serialization

&#x20;  ↓

Photon 네트워크

&#x20;  ↓

상대방 PhotonTransformView

&#x20;  ↓

상대방 Transform 변경





###### \-----------------------------------------------------------------------------------------





###### **PhotonView와 PhotonTransformView의 차이 :**

PhotonView :

네트워크 객체 자체를 관리.

"이 객체는 누구의 것이고,

네트워크에서 어떤 객체인지 관리"



PhotonTransformView :

Transform 데이터를 동기화

"이 객체의 위치와 회전 등을 다른 사람에게 전달"

###### **Controlled Locally :**

이 컴포넌트가 현재 로컬 플레이어에 의해 제어되고 있는가



Controlled Locally = true

→ 내가 직접 조작하는 객체



Controlled Locally = false

→ 내가 직접 조작하지 않는 객체



Controlled Loacally가 true일 때만 동기화됨.



움직이는 스크립트 컴포넌트를 단 플레이어 두명 존재 

마스터 클라이언트 : 하나가 움직이면 다른 쪽에서도 입력을 받아 똑같이 움직임. 

Controlled Loacally가 true이든 false이든 상관없이. 

일반 클라이언트 : Controlled Loacally가 false인 곳은 입력값을 못 받으므로 안 움직인 상태고 ture인 쪽만 움직인 상태 



해결 : Photon View가 내꺼인지 확인해 Photon View를 단 자기 자신만 움직이게(photonView.IsMine)

###### **Photon Animator View :**

내 캐릭터의 애니메이터 상태를 다른 사람의 컴퓨터에도 똑같이 보여주는 역할



컴포넌트				역할

Animator				애니메이션을 실제로 재생

PhotonView			네트워크 객체 관리

PhotonAnimatorView		Animator 상태를 네트워크로 동기화

\------------------------------------------------------------------------------------------------------------------------

Synchronize Parameters :

Animator의 어떤 파라미터를 네트워크로 동기화할지 설정



Synchronization Type :

각 파라미터에는 동기화 방식을 설정



Discrete

변화가 발생했을 때 값을 전달하는 방식.(bool)



Continuous

값이 계속 변하는 경우에 적합해.(float 이동 속도 값)



Disabled

이 Animator Parameter는 Photon을 통해 동기화하지 않는다.
