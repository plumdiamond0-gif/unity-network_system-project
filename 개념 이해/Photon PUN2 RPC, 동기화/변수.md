###### **PhotonNetwork.SerializationRate :**네트워크로 보낼 상태 데이터를 얼마나 자주 준비할지###### **PhotonNetwork.SendRate :**준비된 네트워크 데이터를 얼마나 자주 실제 전송할지\-게임 상태 -> SerializationRate -> 네트워크 데이터 생성 ->  SendRate -> 실제 네트워크 전송 ->  상대방\-SendRate != 상태 데이터가 보내지는 횟수상태 데이터는 최대 약 SerializationRate 만들어짐.전송 처리 기회는 SendRate번.전송할 데이터가 있으면 → 전송전송할 데이터가 없으면 → 아무것도 안 보낼 수도 있음\-게임의 Update→ 플레이어는 계속 움직임SerializationRate→ 그 움직임 중 일부를 네트워크에 동기화Interpolation→ 받은 위치 사이를 부드럽게 연결(보간)\-상태를 더 자주 만들더라도 실제 전송 측에서 전부 즉시 보내지는 못해.그래서 일반적으로 SerializationRate를 SendRate보다 높게 설정하는 건 의미가 제한적이야.SerializationRate <= SendRate\-SendRate와 더 자주 네트워크 처리 속도,  데이터 전달 속도, 네트워크/CPU 부담는 비례 관계SerializationRate와 상태 데이터 생성 빈도, 상태 변화가 전달 빈도, 네트워크 데이터는 비례 관계\-FPS→ 화면을 초당 몇 번 렌더링하는가Ping→ 내 데이터가 상대방까지 갔다 오는 데 걸리는 시간SerializationRate→ 네트워크 상태를 초당 몇 번 직렬화하는가SendRate→ 네트워크 전송 시도/처리를 초당 몇 번 하는가###### \-----------------------------------------------------------------------------------------
