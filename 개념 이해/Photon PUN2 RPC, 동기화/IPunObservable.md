###### **IPunObservable :** 이 클래스는 네트워크 데이터를 직접 동기화할 거야이 클래스는 PUN의 데이터 직렬화 규칙을 따르는 객체라고 알려주는 약속OnPhotonSerializeView : Update()처럼 매 프레임 실행되는 함수가 아님실제로 데이터를 보내고 받는 장소.Photon이 적절한 시점에 이 함수를 호출해줘.PUN이 네트워크 직렬화 주기에 맞춰 자동으로 호출하는 콜백RPC→ 이벤트 전달OnPhotonSerializeView→ 데이터 동기화PhotonStream :네트워크 데이터를 넣거나 꺼내는 통로두 가지 상태.여러 데이터를 보낼 수도 있음그러면 받을 때도 같은 순서로 받아야 해.IsWriting :지금 나는 데이터를 보내는 쪽PhotonView의 소유자, 즉 IsMine == true인 클라이언트가 데이터를 보내.IsReading :지금 나는 다른 클라이언트가 보낸 데이터를 받는 쪽SendNext() :데이터를 네트워크 스트림에 넣어서 보낸다.PUN에서 네트워크 직렬화가 가능한 타입이라면 다양한 데이터를 보낼 수 있어.ReceiveNext() :네트워크 스트림에 들어온 데이터를 꺼낸다.PhotonNetwork.SendRatePhotonNetwork.SerializationRateSerializationRate :네트워크 데이터를 얼마나 자주 직렬화할 것인가?즉 OnPhotonSerializeView() :데이터를 준비하는 빈도와 관련 있어.SendRate :준비된 네트워크 데이터를 실제로 얼마나 자주 전송할 것인가?게임 데이터&#x20;   ↓OnPhotonSerializeView()&#x20;   ↓직렬화&#x20;   ↓전송 큐/버퍼&#x20;   ↓SendRate&#x20;   ↓네트워크0.0초OnPhotonSerializeView()→ position = (0,0,0)→ SendNext()0.1초OnPhotonSerializeView()→ position = (1,0,0)→ SendNext()0.2초OnPhotonSerializeView()→ position = (2,0,0)→ SendNext()...대략 이런 식으로 계속 데이터를 보내.그리고 상대방 컴퓨터에서는 전달받은 데이터를 이용해서:0.0초OnPhotonSerializeView()→ ReceiveNext()→ position = (0,0,0)0.1초OnPhotonSerializeView()→ ReceiveNext()→ position = (1,0,0)0.2초OnPhotonSerializeView()→ ReceiveNext()→ position = (2,0,0)
