###### **RPC :**

원격 함수 호출,내 컴퓨터에서 실행한 함수를 다른 플레이어의 컴퓨터에서도 실행시키는 기능



\------------------------------------------------------------------------------------------------------------------------

일반적인 함수 호출 :

보통 C#에서 함수 호출하면 내 컴퓨터에서만 실행돼.

다른 플레이어의 컴퓨터에는 아무 일도 안 일어나.

\------------------------------------------------------------------------------------------------------------------------

RPC를 사용하면 :

PUN2에서는 : photonView.RPC("함수 이름", 대상);

각 컴퓨터에서 해당 Attack() 함수를 실행시킬 수 있어.

"내가 이 함수를 실행했으니까 다른 사람들도 실행해!"

라고 네트워크를 통해 요청하는 거야.

\------------------------------------------------------------------------------------------------------------------------

사용법 :

\[PunRPC]

void Attack() { }

\[PunRPC]는 Photon에게

"이 함수는 네트워크를 통해 원격 호출할 수 있는 함수야."

라고 알려주는 Attribute야.

\------------------------------------------------------------------------------------------------------------------------

타겟 종류 :

RpcTarget.All → 나 + 다른 모든 플레이어

RpcTarget.Others → 나를 제외한 다른 플레이어

RpcTarget.MasterClient → 방장에게만

RpcTarget.AllBuffered : 재접속될 때 호출

\------------------------------------------------------------------------------------------------------------------------

매개변수 전달 :

\[PunRPC]

void TakeDamage(int damage)

{

&#x20;   hp -= damage;

}

호출:

photonView.RPC(

&#x20;   "TakeDamage",

&#x20;   RpcTarget.All,

&#x20;   30

);

그러면 다른 플레이어들에게

TakeDamage(30)을 실행시키는 것과 같은 효과가 나.

\------------------------------------------------------------------------------------------------------------------------

RPC와 Transform 동기화의 차이 :

계속 다른 플레이어에게 정보를 보내는 건 보통 PhotonTransformView 같은 동기화 시스템을 사용해.

반면 RPC는 특정 사건이 발생했을 때 알려주는 것(이벤트)에 더 적합
